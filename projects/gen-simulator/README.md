# 找回童年

纯前端的 MD、FC、GBA 怀旧游戏模拟器。ROM 通过浏览器 File API 在本机读取，不会上传到服务器。

## 运行

该页面需要通过 HTTP 提供，不能直接使用 `file://` 打开：

```bash
cd projects/gen-simulator
python3 -m http.server 4173
```

然后访问 <http://127.0.0.1:4173>。

## 支持

- MD：`.gen`、`.md`、`.bin`、`.smd`
- FC：`.nes`、`.fds`
- GBA：`.gba`
- 压缩包：`.zip`（加载前先选择对应平台）
- 输入：键盘、Gamepad API 手柄、移动端虚拟按键
- 功能：声音、全屏、即时存档与 SRAM 浏览器持久化
- 存档快捷键：`F5` 保存当前进度，`F8` 打开当前游戏的存档列表

## 默认键位

- 通用：方向 `W/S/A/D`，开始 `B`，选择 `V`
- MD：A/B/C 为 `J/K/L`，X/Y/Z 为 `U/I/O`（`V` 对应 Mode）
- FC/GBA：A/B 为 `J/K`
- GBA 肩键：L/R 保留为 `Q/E`

## 内置游戏

- MD：幽游白书 魔强统一战（简体中文版）
- FC：超级马里奥兄弟（欧洲版）

内置 ROM 位于 `assets/roms/`，封面位于 `assets/covers/`。本地选择的 ROM 仍只在当前浏览器中读取，不会上传。

从主机画面拖入或选择本地 ROM 后，页面会解析卡带信息、保存到陈列架并直接启动模拟器；也可以把 ROM 拖到主机下方的游戏陈列架，仅收藏而不启动。陈列架中的游戏卡带可以拖回上方 ROM 区，像插卡一样直接启动。MD ROM 会读取标准卡带头中的游戏名、发行地区和产品编号。新收藏会先生成本地位图封面，运行成功后再用实际游戏画面自动替换；ROM 和封面都只保存在浏览器 IndexedDB 中。再次打开页面可以直接启动，陈列架上的移除按钮不会影响用户原始文件。

按 `F5` 会把即时存档和游戏截图写入 IndexedDB，不会下载 `.state` 文件；按 `F8` 会打开当前游戏的存档列表，点击任意存档即可直接恢复。模拟器菜单中的“保存状态”和“加载状态”使用相同功能；每个游戏保留最近 8 个即时存档。

页面按设备本地日期区分工作日与休息日：周一至周五每天累计最多运行 5 分钟，周六、周日不限时。工作日用量每秒写入浏览器 `localStorage`，刷新页面、更换游戏或重新打开后仍会继续累计；到达上限时模拟器会暂停并锁定键盘、手柄与触屏输入，次日自动重置。

模拟器核心由 [EmulatorJS](https://emulatorjs.org/) 的稳定 CDN 提供，首次启动需要联网。项目不包含任何商业 ROM；请只加载你合法持有的游戏文件。
