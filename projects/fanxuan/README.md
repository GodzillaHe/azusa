# 饭选

一个给公司同事使用的餐厅随机选择器。应用内置 30 家保利广场、来广营及点评搜索返回的望京周边店家，并根据最近选择记录降低短期重复概率。

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:3000`。不需要地图 Key、地址查询、搜索接口或浏览器定位权限。

## 数据与隐私

- 店家名称、品类、人均与详情链接来自大众点评“保利广场”美食搜索结果，最后核对日期为 2026-08-07。
- 名单位于 `lib/restaurants.ts`，店铺变化时可直接维护该文件。
- 浏览器只保存最近五次抽中的店家，用来降低短期重复概率。
- “看点评”会打开对应店家的大众点评详情页。
